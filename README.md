# NMMF - Norse Mod Menu Framework

One shared mod-settings menu for the Norse overhaul, drawn with the game's own UI: a Mods tab inside its Options screen, built at runtime from Norse's own widget classes. Design survey: `4. plans/norse-realtime-combat-20261116/NMMF-SURVEY.md`.

Status: spike done 2026-11-18 (docs/spike: the Lua prototype, SPIKE-RESULT.txt, mods-tab.png). The C++ framework (API, settings storage, languages) is next.
